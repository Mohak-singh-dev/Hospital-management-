# Medicine Shop Management System

The **Medicine Shop Management System** is a database project developed using MySQL to manage the operations of a medicine shop. It maintains records of customers, employees, medicines, suppliers, sales, and purchases.

The database consists of 8 tables connected through primary keys and foreign keys, ensuring data consistency and referential integrity.

### Features
- Customer and employee management
- Medicine inventory management
- Supplier information management
- Sales and sales item tracking
- Purchase and purchase item tracking
- Relational database design using primary and foreign keys

### Technologies Used
- MySQL
- SQL

### Purpose
The project demonstrates database design, ER diagrams, relational modeling, table creation, and data manipulation using SQL.
